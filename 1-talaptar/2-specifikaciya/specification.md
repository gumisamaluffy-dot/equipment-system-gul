
# СПЕЦИФИКАЦИЯ EQUIPMENT SYSTEM

## 1. Общая информация

**Название проекта:** Equipment System

**Назначение:** Система учёта оборудования и управления заявками на ремонт.

**Цель:** Создать единую систему для хранения информации об оборудовании, контроля его состояния и обработки заявок на ремонт.

## 2. Основные компоненты системы

Система состоит из следующих компонентов:

1. Модуль авторизации.
2. Модуль управления пользователями.
3. Модуль оборудования.
4. Модуль заявок на ремонт.
5. Модуль отчётов.

## 3. Описание компонентов

### 3.1. Модуль авторизации

**Назначение:** Обеспечение входа пользователей в систему.

Функции:
- Регистрация пользователей.
- Вход в систему.
- Проверка логина и пароля.
- Выход из аккаунта.

### 3.2. Модуль управления пользователями

**Назначение:** Управление учётными записями пользователей.

Функции:
- Добавление пользователей.
- Изменение данных пользователей.
- Удаление пользователей.
- Назначение ролей.

Доступ: Администратор.

### 3.3. Модуль оборудования

**Назначение:** Ведение каталога оборудования.

Функции:
- Добавление оборудования.
- Редактирование информации.
- Удаление записей.
- Просмотр списка оборудования.
- Поиск оборудования.
- Просмотр состояния оборудования.

### 3.4. Модуль заявок на ремонт

**Назначение:** Управление обращениями о неисправностях.

Функции:
- Создание заявки.
- Просмотр заявок.
- Описание неисправности.
- Изменение статуса заявки.
- Отслеживание выполнения ремонта.

### 3.5. Модуль отчётов

**Назначение:** Предоставление информации о состоянии оборудования.

Функции:
- Формирование отчётов.
- Подсчёт количества оборудования.
- Подсчёт неисправного оборудования.
- Просмотр статистики.

Доступ: Руководитель.

## 4. Структура данных

Основные сущности системы:

- Пользователь.
- Оборудование.
- Заявка на ремонт.
- Отчёт.

Каждая сущность имеет собственные поля и характеристики.

## 5. Интерфейсы компонентов

| Компонент | Входные данные | Результат |
|---|---|---|
| Авторизация | Логин, пароль | Вход в систему |
| Пользователи | Данные пользователя | Создание или изменение аккаунта |
| Оборудование | Название, описание, состояние | Запись об оборудовании |
| Заявки | Описание неисправности | Создание заявки |
| Отчёты | Данные оборудования | Отчёт о состоянии |

## 6. Ограничения системы

1. Управление пользователями доступно только администратору.
2. Для входа необходимы логин и пароль.
3. Система должна поддерживать не менее 500 записей оборудования.
4. Интерфейс должен работать в Google Chrome и Microsoft Edge.
5. Данные должны храниться в единой базе данных.

## 7. Критерии проверки

Система считается соответствующей спецификации, если:

- Пользователь может войти в систему.
- Администратор может управлять пользователями.
- Оборудование можно добавлять и редактировать.
- Пользователь может искать оборудование.
- Сотрудник может создавать заявки.
- Мастер может изменять статус заявки.
- Руководитель может просматривать отчёты.
