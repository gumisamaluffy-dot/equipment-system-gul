
# СЛОВАРЬ ДАННЫХ EQUIPMENT SYSTEM

## 1. Общая информация

Словарь данных описывает основные сущности системы Equipment System, их поля, типы и назначение.

## 2. Сущность «Пользователь» (User)

| Поле | Тип данных | Описание |
|---|---|---|
| user_id | Integer | Уникальный идентификатор |
| username | String | Имя пользователя |
| password | String | Пароль пользователя |
| email | String | Электронная почта |
| role | String | Роль пользователя |

## 3. Сущность «Оборудование» (Equipment)

| Поле | Тип данных | Описание |
|---|---|---|
| equipment_id | Integer | Уникальный идентификатор |
| name | String | Название оборудования |
| description | Text | Описание оборудования |
| category | String | Категория оборудования |
| status | String | Состояние оборудования |
| location | String | Местонахождение |

## 4. Сущность «Заявка на ремонт» (Repair Request)

| Поле | Тип данных | Описание |
|---|---|---|
| request_id | Integer | Номер заявки |
| equipment_id | Integer | Идентификатор оборудования |
| user_id | Integer | Идентификатор сотрудника |
| problem_description | Text | Описание неисправности |
| request_date | Date | Дата создания заявки |
| status | String | Статус заявки |
| technician_id | Integer | Идентификатор мастера |

## 5. Сущность «Отчёт» (Report)

| Поле | Тип данных | Описание |
|---|---|---|
| report_id | Integer | Номер отчёта |
| report_date | Date | Дата формирования |
| total_equipment | Integer | Общее количество оборудования |
| damaged_equipment | Integer | Количество неисправного оборудования |

## 6. Связи между сущностями

1. Один пользователь может создавать несколько заявок.
2. Одно оборудование может иметь несколько заявок на ремонт.
3. Каждая заявка связана с конкретным оборудованием.
4. Мастер может обрабатывать несколько заявок.
5. Отчёты формируются на основе данных об оборудовании.

## 7. Заключение

Словарь данных определяет структуру хранения информации в Equipment System и используется при проектировании базы данных.
