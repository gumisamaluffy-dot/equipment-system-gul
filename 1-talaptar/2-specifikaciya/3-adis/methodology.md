# Метод и стратегия разработки

## 1. Метод разработки

Для создания системы учёта оборудования используется поэтапный метод разработки.

Работа разделена на несколько этапов:
1. Анализ требований.
2. Проектирование системы.
3. Разработка интерфейса и базы данных.
4. Тестирование системы.
5. Исправление ошибок и подготовка итогового проекта.

## 2. Стратегия разработки

Разработка выполняется постепенно. Сначала создаётся основная структура системы, затем добавляются функции учёта оборудования, управления заявками и формирования отчётов.

## 3. Инструменты разработки

- GitHub — хранение файлов проекта.
- Draw.io — создание диаграмм.
- SQL — работа с базой данных.
- HTML и CSS — создание интерфейса.

## 4. Ожидаемый результат

Готовая система позволит учитывать оборудование колледжа, находить нужные устройства и управлять заявками на ремонт.
