# Проектирование пользовательского интерфейса

## 1. Общая информация

Пользовательский интерфейс системы учёта оборудования колледжа предназначен для удобного взаимодействия пользователей с системой.

Интерфейс должен быть простым, понятным и не требовать специальных технических знаний.

## 2. Основные страницы системы

### 2.1. Страница входа

Предназначена для авторизации пользователей.

На странице будут расположены:
- поле для ввода логина;
- поле для ввода пароля;
- кнопка «Войти».

### 2.2. Главная страница

После входа пользователь попадает на главную страницу.

На ней отображаются:
- основное меню;
- краткая информация о системе;
- переходы к основным разделам.

### 2.3. Страница оборудования

Предназначена для просмотра и управления оборудованием колледжа.

На странице будут расположены:
- список оборудования;
- строка поиска;
- кнопка добавления оборудования;
- информация о состоянии и местоположении устройств.

### 2.4. Страница заявок на ремонт

Позволяет создавать и просматривать заявки.

Основные элементы:
- список заявок;
- описание неисправности;
- дата создания;
- статус заявки;
- кнопка создания новой заявки.

### 2.5. Страница отчётов

Предназначена для просмотра общей информации о состоянии оборудования и заявках.

На странице могут отображаться:
- количество оборудования;
- количество неисправных устройств;
- количество открытых и завершённых заявок.

## 3. Удобство использования

При проектировании интерфейса учитываются следующие требования:

- понятное расположение элементов;
- простая навигация между страницами;
- читаемый текст;
- единый стиль оформления;
- отображение сообщений об успешных действиях и ошибках.

## 4. Адаптация интерфейса

Интерфейс должен корректно отображаться на компьютерах и других устройствах с разными размерами экранов.

## 5. Ожидаемый результат

В результате проектирования будет подготовлена структура основных страниц системы. Пользователи смогут быстро находить нужные разделы, просматривать оборудование и работать с заявками на ремонт.
