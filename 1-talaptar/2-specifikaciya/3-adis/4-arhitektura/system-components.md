# Компоненты системы

## 1. Общая информация

Система учёта оборудования колледжа состоит из нескольких компонентов, каждый из которых выполняет определённую задачу. Все компоненты взаимодействуют между собой и обеспечивают правильную работу системы.

## 2. Основные компоненты

### 2.1. Модуль авторизации

Отвечает за вход пользователей в систему.

Основные функции:
- проверка логина и пароля;
- определение роли пользователя;
- предоставление доступа к нужным разделам.

### 2.2. Модуль управления оборудованием

Предназначен для работы с информацией об оборудовании.

Основные функции:
- добавление новых устройств;
- редактирование информации;
- удаление записей;
- поиск оборудования;
- просмотр состояния устройств.

### 2.3. Модуль управления заявками

Отвечает за обработку заявок на ремонт.

Основные функции:
- создание заявок;
- просмотр заявок;
- изменение статусов;
- хранение информации о неисправностях.

### 2.4. Модуль отчётов

Предназначен для получения общей информации о работе системы.

Основные функции:
- отображение количества оборудования;
- просмотр неисправных устройств;
- подсчёт заявок;
- отображение завершённых ремонтов.

### 2.5. Модуль базы данных

Отвечает за хранение всей информации системы.

В нём сохраняются:
- данные пользователей;
- сведения об оборудовании;
- заявки на ремонт;
- история изменений.

## 3. Взаимодействие компонентов

Компоненты работают совместно:

1. Пользователь входит в систему.
2. Модуль авторизации проверяет его данные.
3. Пользователь выбирает необходимый раздел.
4. Соответствующий модуль обрабатывает запрос.
5. База данных сохраняет или возвращает информацию.
6. Результат отображается на экране.

## 4. Преимущества разделения на компоненты

Разделение системы на отдельные модули позволяет:
- упростить разработку;
- быстрее находить и исправлять ошибки;
- удобнее проверять отдельные функции;
- добавлять новые возможности;
- облегчить дальнейшее обслуживание системы.

## 5. Итог

Разработанная структура компонентов позволяет разделить систему на логические части. Каждый модуль отвечает за определённые функции, а их совместная работа обеспечивает учёт оборудования и управление заявками на ремонт.
