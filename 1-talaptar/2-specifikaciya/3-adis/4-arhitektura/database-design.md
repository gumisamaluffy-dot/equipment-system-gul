# Проектирование базы данных

## 1. Назначение базы данных

База данных предназначена для хранения информации об оборудовании колледжа, пользователях и заявках на ремонт.

Она позволяет организовать данные в удобном виде, быстро находить необходимую информацию и отслеживать состояние оборудования.

## 2. Основные таблицы

### Таблица «Пользователи» (Users)

Хранит информацию о пользователях системы.

| Поле | Назначение |
|---|---|
| user_id | Уникальный номер пользователя |
| full_name | ФИО пользователя |
| login | Логин для входа |
| password | Пароль пользователя |
| role | Роль пользователя |

### Таблица «Оборудование» (Equipment)

Хранит информацию об устройствах колледжа.

| Поле | Назначение |
|---|---|
| equipment_id | Уникальный номер оборудования |
| name | Название оборудования |
| inventory_number | Инвентарный номер |
| category | Категория оборудования |
| location | Местоположение |
| status | Состояние оборудования |

### Таблица «Заявки» (Requests)

Хранит информацию о заявках на ремонт.

| Поле | Назначение |
|---|---|
| request_id | Уникальный номер заявки |
| user_id | Номер пользователя |
| equipment_id | Номер оборудования |
| description | Описание проблемы |
| request_date | Дата создания заявки |
| status | Статус заявки |

## 3. Связи между таблицами

Таблицы связаны между собой с помощью ключей:

- `user_id` связывает пользователей с их заявками.
- `equipment_id` связывает оборудование с заявками.
- `user_id` и `equipment_id` в таблице заявок являются внешними ключами.

Один пользователь может создать несколько заявок. Одно устройство также может иметь несколько заявок на ремонт.

## 4. Первичные и внешние ключи

**Первичный ключ (Primary Key)** — поле, которое уникально определяет каждую запись в таблице.

**Внешний ключ (Foreign Key)** — поле, которое связывает одну таблицу с другой.

Использование ключей помогает избежать путаницы и поддерживать правильные связи между данными.

## 5. Ожидаемый результат

В результате проектирования будет создана структура базы данных, которая позволит хранить сведения о пользователях, оборудовании и заявках на ремонт в упорядоченном виде.
