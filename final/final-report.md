# Итоговый отчёт проекта Equipment System

## 1. Введение

Equipment System — проект информационной системы для учёта оборудования колледжа и управления заявками на ремонт.

Проект направлен на упрощение хранения информации об оборудовании, ускорение поиска устройств и улучшение контроля ремонтных работ.

## 2. Актуальность проекта

При обычном ручном учёте могут возникать трудности с поиском информации, обновлением данных и отслеживанием заявок на ремонт.

Создание единой системы позволит организовать эти процессы и сделать работу с оборудованием удобнее.

## 3. Цель и задачи

**Цель:** спроектировать систему учёта оборудования колледжа и управления заявками на ремонт.

**Задачи:**
- определить требования к системе;
- определить роли пользователей;
- спроектировать структуру базы данных;
- описать основные компоненты системы;
- подготовить диаграммы и макеты;
- определить способы проверки функций.

## 4. Пользователи системы

В проекте предусмотрены четыре роли:

- **Администратор** — управление пользователями и оборудованием.
- **Сотрудник** — просмотр оборудования и создание заявок.
- **Мастер** — обработка заявок и изменение их статусов.
- **Руководитель** — просмотр информации и отчётов.

## 5. Основные функции

Система должна обеспечивать:
- авторизацию пользователей;
- добавление и редактирование оборудования;
- поиск и просмотр устройств;
- создание заявок на ремонт;
- изменение статусов заявок;
- просмотр отчётов.

## 6. Проектирование базы данных

Предусмотрены три основные таблицы:

1. **Users** — информация о пользователях.
2. **Equipment** — сведения об оборудовании.
3. **Requests** — информация о заявках на ремонт.

Таблицы связаны с помощью первичных и внешних ключей.

## 7. Архитектура системы

Архитектура включает три основных компонента:

- пользовательский интерфейс;
- серверную часть;
- базу данных.

Пользователь выполняет действия через интерфейс. Серверная часть обрабатывает запросы и взаимодействует с базой данных.

## 8. Метод разработки

Для организации работы выбран поэтапный подход:

1. Анализ требований.
2. Проектирование системы.
3. Проектирование базы данных.
4. Разработка интерфейса.
5. Тестирование.
6. Подготовка итоговых материалов.

Общая продолжительность проекта составляет 144 часа.

## 9. Проверка системы

Для проверки предусмотрены следующие направления:
- правильность авторизации;
- добавление и поиск оборудования;
- создание заявок;
- изменение статусов;
- просмотр отчётов;
- проверка удобства интерфейса.

## 10. Используемые инструменты

- GitHub — хранение и организация файлов проекта.
- Draw.io — создание диаграмм.
- SQL — проектирование базы данных.
- HTML и CSS — проектирование веб-интерфейса.
- Markdown — оформление документации.

## 11. Ожидаемый результат

После реализации система должна позволять хранить сведения об оборудовании в одном месте, быстро находить устройства, создавать заявки на ремонт и отслеживать их состояние.

## 12. Заключение

В ходе проектирования Equipment System были подготовлены материалы с описанием требований, компонентов, стратегии разработки, архитектуры и базы данных.

Проект создаёт основу для разработки удобной системы учёта оборудования колледжа и управления заявками на ремонт.
